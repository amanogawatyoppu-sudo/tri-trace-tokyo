# noteを1本つくる手順

担当を次の順番で呼び、前の担当の合格が出てから次へ進む。

1. neta でネタ候補を10本出す
2. bunseki で10本に優先順位をつける → 数字がなければ「数字なし」と正直に報告する → 順位表を私に見せて1本選んでもらう
3. kousei で見出し構成を作る → 私に見せて確認を取る
4. shippitsu で本文を書く
5. review で判定する
   - 不合格なら shippitsu に差し戻す。これを最大3回まで繰り返す
   - 3回で合格しなければ、止めて私に理由を報告する
6. kousei-check で誤字脱字を直す
7. rewrite で人の文章にする
8. gazou で画像のプロンプトを作る
9. soushoku で見た目を整える
10. toukou で公開前パッケージを作る → 私の最終確認でOKが出たら、原稿を output/note/ に「日付_タイトル.md」（例：2026-10-04_タイトル.md）で保存する

## 止まるところ

- 2のネタ選び（順位表を見て選ぶ）
- 3の構成確認
- 10の最終確認（OKが出るまで保存しない）

この3箇所では必ず私の返事を待つ。それ以外は止まらず進める。

## 報告のしかた

各担当が終わるたびに、1行で「誰が終わって、次は誰か」を書く。
長い中間成果物は、私が求めたときだけ全文を見せる。
