# TRI//TRACE : TOKYO MAP REFORGE 並列A — 上野 GREEN HEIGHTS（レビュー待ち）

上野戦区の中心部だけを作り直しました。テーマは「広い見通し・自然の地形・高低差」です。隠れる街ではなく、遠くの敵が見えたうえで、木・坂・石段・高台のどれを使って逃げるかを選ぶ地区にしました。

- 渋谷・新宿・秋葉原を含め、上野以外の地区は変更していません。ゲームルール・AI・TRACE・LOCK POINT・会議・オンライン同期・キャラクター・全マップ共通のレンダラーとメッシュも変更なし
- 上野の範囲の外は map-reforge-base（bbe30ec）とまったく同じです。範囲外のプリミティブ・街灯・建物・電柱・電線・道路・拠点位置のハッシュをテストで比較しています
- 戦略拠点「上野の山」、LUNA 拠点、LOCK POINT、不忍池の位置は変えていません。戦略拠点の半径150の台地の上には何も建てていません（テスト）
- AI の経路グラフは地形から自動で作られるので、新しい石段・坂・木立の道もそのまま AI が使います。LUNA・SOL・STAR の拠点から戦略拠点まで歩いて行けることもテストで確認しました
- ブランチは `map-reforge-ueno`（map-reforge-base bbe30ec から）。コミットのみで、push はしていません

## 1. 上野の作り
BEFORE の上野は、台地（高さ130）と西の大きな坂、南の石段、博物館の箱、建物が数棟あるだけの広い空き地でした。

**3つのルート**（広場 → 戦略拠点の距離。A/B/C はつながる場所が6か所ある）
- **A. GRAND PROMENADE（約1,710）**: 幅200のまっすぐな大通りを北へ進み、台地の西の崖に沿った WEST RAMP（勾配0.43）で台地に上がるルート。いちばん速く、夜は東側だけに並んだ街灯で明るい。そのかわり、台地の縁とテラスから全長が見える（テラスから広場の85%以上が見えることをテスト）
- **B. GROVE PATH（約2,570）**: 大通りの西の木立の道。幹（幅24、約0.9m）と高さ46の生垣、高さ44の低い石壁、藤棚で、数歩ごとに視線が切れる（視線の20〜70%が遮られることをテスト）。ただし迷路にはせず、生垣には幅110以上の切れ目が3か所あって大通りへ抜けられる。夜は街灯の光が届かず暗い（60%以上が暗いことをテスト）
- **C. TERRACE ROUTE（約750）**: LUNA 拠点の軸線上の STONE AXIS（2段＋踊り場、各段の高さ65、勾配0.46）を登って GREEN TERRACE へ出るルート。距離は最短だが、登りでは速度が0.8倍に落ちる。テラスからは広場と大通りの入口を見下ろせるので、偵察に向いている

**A/B/C のつながり**: 生垣の切れ目3か所（A↔B）、池沿いの広場（A↔B↔C）、北の CANOPY WALK（A↔B、さらに東の芝生へ）、台地の上（A の坂の上 ↔ C のテラス）。

**CHASE MOMENT**（`run-30s.jpg` の順番）
1. 広場や門の内側から、敵がどのルートに入ったかが見える（大通りは丸見え、木立は入口だけ見える）
2. STONE AXIS の長い石段で追いかける。踊り場で一度高さがそろい、上の段ではテラスの欄干で前が切れる
3. WEST RAMP の頂上では、坂の向こうの大通りが坂の稜線で一度隠れる（`high-ground.jpg` の下段）
4. テラスや台地の縁からは、下の広場・大通り・木立の入口にいる敵が見える
5. 木の幹の陰に一瞬だけ隠れられる（幹が視線を切ることをテスト）。幹と幹の間は70以上あけていて、体（直径28）が引っかかる狭いすき間（0〜60）はどこにもない（テスト）

狭い路地が続く場所は作っていません。

**ランドマーク（すべて架空のデザインで、実在の施設は模していない）**
1. **GREEN TERRACE**: 台地の南に張り出した石のテラス（高さ130）。欄干は石段の幅だけ開けてある
2. **STONE AXIS**: 拠点の軸線上の、幅140の長い石段。段鼻のライン、両脇の灯籠の石柱、縁石。夜の段鼻の照明は既存の階段照明（`stairLights.ts`）がそのまま付くので、夜の階段の見やすさは前と同じかそれ以上
3. **CANOPY WALK**: 北の崖下を東西に通る並木道。大きな樹冠が頭上を覆い、東の芝生へ抜ける
4. **CULTURE GATE**: 石段の下、広場の南端に立つ石の門（柱2本＋梁、通り抜けの高さ214）。「上野 UENO GREEN HEIGHTS」の額
5. ほかに、台地の北側の低い石造りの文化館（UENO HALL、高さ200）と、木立の中の藤棚

**木はゲームプレイの道具**: 幹は当たり判定あり（隠れられる）。樹冠は描画だけで高い位置（幹の上、地面から270〜330）にあり、カメラに近づくと透ける（`nearFade`）。木は23本だけで、ジャングルにはしていない。見通しは一定の間隔で開ける。移動をふさぐ位置には置いていない（大通り・並木道・坂の上を歩いて抜けられることをテスト）。

**色と夜**
- 深い緑、石の灰色、落ち着いた茶色、暖色の街灯、少しの白。ネオンはほぼなし。上野の街灯の色（暖色・白・葉の緑）は、陣営の色から色相を24°以上離した（テスト）
- 街灯12本（大通りの東側に4本、広場・軸・芝生・並木道）。夜は大通りと広場が明るく、木立は暗い
- 白飛び（`expo.py`、L≥235 の画素）: 昼 0.1〜1.9%、夕方 0.1〜1.0%、夜 0.3〜4.0%（BEFORE は昼 0.0〜0.7%、夕方 0.1〜0.8%、夜 0.1〜1.1%）。夜の最大は木立で、画面に入る地区外の明るい建物と街灯の光

## 2. 実装中に変えたところ
- **上野の地面が街の地面に負けて白く見えていた**: 地面の高さ0.5の差では遠くで深度が足りず、街の地面が透けていた。渋谷・秋葉原と同じ polygonOffset を上野の地面だけに付けて直した（共通の地面には触れていない）
- **文化館の位置を北へ寄せた**: 最初の位置では戦略拠点の半径150に4ほど入っていたため
- **木立の木2本と、南の生垣の長さを調整した**: 生垣と幹の間が体より狭くなる場所と、生垣の切れ目をふさぐ幹があったため
- **B の経路は、木立を通って生垣の切れ目から A に合流し、WEST RAMP で台地へ上がる形にした**: 台地の西と北は崖なので、上がれるのは坂と石段だけです（BEFORE と同じ）
