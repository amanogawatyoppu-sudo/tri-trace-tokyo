# 秋葉原 ELECTRIC GRID 改修案（実装前の提案）

画像: `before-now.jpg`（いまの秋葉原）、`proposal-plan.jpg`（平面図 BEFORE / AFTER 案）

## いまの秋葉原で起きていること
- 線路の西、神田川の北岸から LUNA の拠点まで、約 1,200×900 の灰色の空き地になっている。範囲内の建物は2棟だけ。
- 神田川と聖橋の周りが「建てない場所」として広く確保されていて、そのせいで街区ごと消えている。
- 戦略拠点「電気街」は川沿いの柵の前にあるが、周りに道も店もない。名前だけで秋葉原らしさがない。
- 北西にあるれんが色のアーケード（アメ横風）は、ほかと何もつながっていない。

## 方針
渋谷・新宿と同じ手順で作る。いまの街を生成したあと秋葉原の中心部だけを差し替え、それ以外の東京は変えない。外側が変わっていないことはハッシュのテストで確認する。

LUNA の拠点・LOCK POINT・戦略拠点の位置、神田川と聖橋は変えない。ゲームルール・AI・TRACE・会議・オンライン同期にも触らない（AI の経路は地形から自動で作られるので、新しい道と階段はそのまま使われる）。

渋谷の「大きな広告と大交差点」、新宿の「超高層とデッキ」に対して、秋葉原は **細い道と小さい店が密集した街** にする。建物は 2〜6 階の細長い雑居ビルが中心で、高いものは作らない。

## 1. 3つのルート
- **A. MAIN ELECTRIC STREET（大通り）**: 聖橋の軸に合わせた南北の通り（幅 280、渋谷の大通りの 3/4）。南は靖国通り（川の南）から聖橋を渡り、北はアーケードの前まで続く。両側に間口の狭い店が並ぶ。まっすぐで障害物がなく速いが、店先・歩道橋・LOCK YARD から丸見え。
- **B. COMPONENT ALLEY（部品店の路地）**: 大通りの西の街区を、幅 3 マス（約 110）の曲がった路地にする。小さな部品店・ゲーム店・ジャンク屋が並ぶ。まっすぐ見通せる行・列は作らない（渋谷の迷路と同じテスト）。入口は大通り側に2か所、アーケードの南口、川沿いの小道。大通りの東側にも、戦略拠点へ下りる短い部品店の小道を2本つくる。
- **C. SERVICE CUT（サービス通路）**: 2本。
  - 高架沿いの裏通路: 拠点の南から高架の壁沿いに戦略拠点の北東角まで抜ける。拠点から戦略拠点への最短の道。入口は POWER NODE（配電設備）の陰の切れ目と、出口は小さな階段の下。どちらも正面からは見えにくい。
  - 店舗裏の抜け道: 大通りの西側の店の搬入口から路地の中へ入る、シャッター半開きの細い通路。

拠点から戦略拠点へは、C が最短・B が中間・A が遠回りだが最も速く走れる。逆に川の南（神田・中央方面）から来る敵は、大通りを通るのがいちばん早い。

## 2. CHASE MOMENT（秋葉原だけの追跡の場面）
- 大通りで見つかったら、路地の入口（店の間の切れ目）に飛び込んで視線を切る。
- 路地から大通りを横切って東の小道へ渡る瞬間だけ、また丸見えになる。
- 店舗裏の搬入口から路地の奥へ消える。
- 配電設備・室外機・ケーブルラックの陰で待ち伏せする。
- 3本の道（大通り・部品店の小道・裏通路）が同じ広場（DATA JUNCTION）に出る。どこから来るか読み合いになる。

詰まり防止: 路地・通路はすべて幅 100 以上。行き止まりは作らず、どの路地も2か所以上に抜ける。小物（室外機・自販機・看板）は壁沿いに寄せ、通路の真ん中には置かない。徒歩で全ルートを通れることをテストで確認する。

## 3. 小さな立体交差
- **GRID GATE**: 大通りの上を渡る幅の狭い歩道橋（高さ 120、新宿のデッキより低い）。路地の西側と LOCK YARD 側をつなぐ。橋の側面に「ELECTRIC GRID」の帯。階段の下は隠れ場所になる。
- 高架沿いの裏通路の出口に、短い階段と階段下の通り抜け。

## 4. ランドマーク（すべて架空のデザイン）
1. **GRID TOWER**: アーケードの東口と拠点の間に立つ中型の鉄塔（高さ約 25m、細い格子）。上から周りのビルへ配線が放射状に張られ、細い青と白の光のラインが走る。大通りを北に向くと正面に見える。
2. **CIRCUIT ARCADE**: いまのアーケードを作り直す。位置・大きさ・東西の出入口はそのまま（既存のテストもそのまま通る）。中を細長い電子部品の通路にし、天井に配線と回路模様の光の線、両側に小さな店の棚。南側に路地へ抜ける出入口を1つ足す。
3. **DATA JUNCTION**: 戦略拠点の広場。路地が集まる場所に、低い電子掲示板（LED の文字が流れる板）を広場の縁に並べる。拠点の半径 150 は空けたまま。
4. **POWER NODE**: 高架沿いの裏通路の入口にある、壁一面の配電盤・変圧器・ケーブルラック。裏通路の目印。

どれも通常の三人称カメラの視界（地上から 10m 前後）に収まる高さに主な見どころを置く。

## 5. 街並み（同じモデルを再利用）
- 1〜2 階: 間口 3〜5m の店先、シャッター、小さな LED 表示、店名帯。架空の店名（例: 回路堂、PARTS 99、GRIDBOX、ジャンク通信、8bit 堂）だけを使う。実在の企業・店のロゴは使わない。
- 中層: 細い縦看板を何本も（渋谷の大型画面の代わりに、小さい看板の数で密度を出す）、換気扇、室外機。
- 裏側・路地側: 配管、ケーブルラック、配電箱、室外機の列、細い外階段、裏口。
- 通り: 電柱と電線（渋谷・新宿より本数を多く）、自販機、柵、小型照明。

## 6. 視覚言語
- 色: 白・黒・電気ブルー・緑・少量の赤。ピンク／シアン（渋谷）と大きなガラス面（新宿）は使わない。
- **電気ブルーの色相**: 秋葉原は LUNA（青）の拠点なので、LUNA の青と見分けがつくよう、紫寄りの青（色相 240° 前後）にする。緑・赤も各陣営の色から 24° 以上離し、テストで確認する。
- 細い発光ライン、細かい文字、回路基板のような模様。看板は渋谷と同じく主役・補助・背景の3段階。

## 7. 夜景と NPC の見やすさ
- 夜も真っ暗にしない。店先の灯り、LED 表示、配線の光、看板の灯りで、路地と入口の形を読めるようにする。
- サービス通路の入口には、小さな白と緑の誘導灯を付けて暗闇に埋もれないようにする。
- 路地の壁は中くらいの暗さにそろえ、青い光を地面の近くに当てない。キャラクターの輪郭と陣営色が背景に溶けないようにする。白飛びは `expo.py` で測る。

## 8. 性能
- 室外機・電柱・配電箱・看板の枠・自販機・柵・小型照明は InstancedMesh で1種類1回の描画にする。
- 建物と看板は材質ごとに結合し、看板の文字は1枚のアトラスにまとめる。電線は1本のジオメトリにまとめる。
- BEFORE / AFTER で draw calls・三角形・テクスチャメモリ・フレーム時間を比べる。

## 確認したいこと
1. 大通りを聖橋の軸（LOCK POINT の西）に通す案でよいか。高架沿いに通す案もあるが、LOCK POINT と線路の間は幅が約 220 しかなく、店を並べられない。
2. いまのアーケードを CIRCUIT ARCADE に作り直してよいか（位置と東西の出入口はそのまま、南口を1つ追加）。
3. 電気ブルーを紫寄りの青にしてよいか（LUNA の青と区別するため）。
