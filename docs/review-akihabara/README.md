## 1. 秋葉原の作り
v10.0 の秋葉原は、神田川と聖橋の「建てない場所」で街区ごと消え、線路の西から拠点まで約 1,200×900 の空き地で、建物は2棟でした。

**3つのルート**（拠点 → 戦略拠点の距離は C が最短、B が中間、A が遠回りだが最も速い。テストで確認）
- **A. MAIN ELECTRIC STREET**: 聖橋の軸（x 2222）の南北の通り。幅 280 のうち車道は 160 だけで、両側の歩道 60 に電柱・車止め・自販機・店先の商品・のぼりを並べた。アーケードの南の壁から橋のたもとまで見通せる（速いが店先・歩道橋・LOCK YARD から丸見え）
- **B. COMPONENT ALLEY**: 大通りの西の部品店の路地（アーケードの南口 → 背骨の路地 → 西の路地 → 南西の路地 → 川沿い → 南東の路地 → 大通り）と、大通りの東の部品店の小道（LOCK YARD → DATA JUNCTION）。どの路地も曲がっていて、大通りからは中を見通せない（視線の切れ方を8組テスト）
- **C. SERVICE CUT**: 高架沿いの裏通路（拠点の南 → POWER NODE の陰 → DATA JUNCTION の北東角、最短）と、1階が通り抜けになっている建物2棟（P1: 路地 ↔ 大通り、R2: LOCK YARD ↔ 裏通路）。入口は正面から見えにくく、白と緑の小さな誘導灯で夜も見つけられる

**詰まり防止**: 路地と通路はすべて幅 100 以上。電柱・自販機・メーターは壁に寄せ、真ん中は 76 以上空いている（テスト）。行き止まりはない（平面図の塗りつぶしと搬入口の両方向の通り抜けテスト）。

**建物（手作り14棟）**: 2〜6階の細い雑居ビル。間口 3.5m ほどの店先、店名帯、LED の流れる表示、細い縦看板（28本）、各階のテナント表示、室外機と換気扇、裏側はケーブルラック・配管・メーター・裏口。店名はすべて架空（回路堂、PARTS 99、GRIDBOX、ジャンク通信、8bit堂、ラジオ横丁、LED工房、基板屋、CABLE LAB、中古PC、TRACE GAMES、電脳館）。

**ランドマーク（すべて架空のデザイン）**
1. **GRID TOWER**: アーケードの東口の広場に立つ白黒の格子の鉄塔（高さ 650）。高さ 430 のリングから周りの屋上・電柱へケーブルを張った（描画のみ・当たり判定なし。いちばん低いところでも 265、テストで確認）。脚に紫寄りの青の光のライン、足元の広場は回路模様の舗装
2. **CIRCUIT ARCADE**: 既存のアーケードを同じ位置・同じ東西の出口のまま作り直し、南口（幅 106）を追加。中は部品店の棚、天井に配線と回路模様の光
3. **DATA JUNCTION**: 戦略拠点の広場。暗い御影石の舗装、各路地の出口から拠点へ集まる回路の線、縁に LED の掲示板3枚（拠点の半径 150 の外）
4. **POWER NODE**: 裏通路の高架側の壁の配電盤・変圧器・ケーブルトレイ・警告板
5. **GRID GATE**: 大通りを渡る幅の狭い歩道橋（高さ 80）。側面に「秋葉原 電気街・GRID GATE・ELECTRIC GRID」の帯

**夜と色**
- 光の色は白・紫寄りの電気ブルー（0x5a4bff、色相約 245°）・緑・少量の赤だけ。陣営の色から色相を 24°以上離した（テスト）。秋葉原の一般の建物の看板の色も同じ4色にした（前は黄色とシアンが STAR・LUNA に近かった）
- 夜も真っ暗にならない（店先・LED・看板・誘導灯）。路地はルール上の暗さのまま、画面上の明るさだけを足している
- 白飛び（`expo.py`、L≥235 の画素）: 昼 0.2〜3.0%（v10.0 は 0.0〜8.5%）、夕方 0.0〜3.1%、夜 0.0〜4.3%。夜の最大は GRID GATE の上と大通りで、主に画面に入る御徒町の駅名板と地区の外の明るいビル

## 2. 案から変えたところ
- **大通りの川の南への延長はやめた**。聖橋の南のたもとに丸の内のガラスのタワーがあり、これを動かさないと通せないため。大通りはアーケードから聖橋の北のたもとまで
- **GRID GATE の高さは 120 → 80**。案の高さだと西の階段が P1 の搬入口の出口をふさぎ、行き止まりになった。歩道橋を北へ寄せて低くし、階段を搬入口より北で終わらせた（下を通る高さは 68 あり、人は普通に通れる）
- **裏通路の出口の「短い階段と階段下の通り抜け」は作らず、R2 の1階の通り抜けにした**
- **路地の見通しは、渋谷の迷路と同じ行・列のテストではなく、大通り・LOCK POINT・拠点から路地の中への視線8組で確認**（手で配置した路地なので、格子のテストが当てはまらない）

## 3. 性能（BEFORE v10.0 / AFTER、同じ地点・同じ向き、tier 0、1366×768）

| 地点（昼） | draw calls | 三角形 | フレーム時間（ソフトウェア描画） |
|---|---|---|---|
| 大通り | 156 → 186 | 124,897 → 161,921 | 575 → 748 ms |
| 路地 | 262 → 286 | 156,911 → 176,345 | 547 → 891 ms |
| 裏通路 | 250 → 272 | 148,495 → 172,485 | 534 → 789 ms |
| DATA JUNCTION | 239 → 262 | 134,921 → 172,005 | 554 → 784 ms |
| 塔の広場 | 137 → 172 | 123,193 → 160,413 | 416 → 633 ms |
| アーケード | 216 → 233 | 158,621 → 178,669 | 545 → 800 ms |

- 夜は draw calls が −7〜+16、三角形が −14k〜+4k（夜は前から街灯のぶん多い）
- テクスチャメモリ 91.9 → 102.6 MB（+10.7 MB。秋葉原の看板アトラス 1024×2048 が1枚。外壁テクスチャは街と共用）。ジオメトリ 13.8 → 15.1 MB
- 材質ごとに結合し、室外機・換気扇・タンク・配管・ケーブルラック・メーター・商品の箱・ガチャ・車止め・変圧器・LED は InstancedMesh（シーンへの追加は 25 個、秋葉原の描画は 18,276 三角形。テストで上限を確認）
- フレーム時間は GPU なしのソフトウェア描画なので実機とは別物ですが、増え幅は新宿と同じくらい。**スマホ実機で重くないか確認をお願いしたい点**。重ければ、看板アトラスを 1024×1024 に縮めるのと、中層の看板を減らすのが次の手
