## 1. COMPONENT ALLEY
- 路地に面した店先の小さな看板・文字を 185 → 139 個に減らした（−25%）。店の数・店名帯・縦看板・ルートはそのまま
- 減らしたもの: 柱のポスターを半分、各階のテナント表示を1階おき、窓のポスターを半分、LED の流れる表示を約半分、歩道に立てた値札（体の高さにあって人の輪郭とかぶる）
- 路地の店のショーウィンドウ（棚の絵）26面を一段暗くした（看板の明るさ 0.6 → 0.42）。大通りの店先は元のまま

## 2. GRID TOWER
- 4本の脚の紫寄りの青の光のラインを太くして（1.4 → 2.4）、夜の明るさを上げた（他の看板より一段明るい）
- そのラインを塔の上のマストまで延ばし、赤いライトまで縦の線がつながるようにした
- 塔の大きさ・高さ・形・看板は変えていない

## 3. DATA JUNCTION
- 拠点そのものの光（光の柱・足元の光）を渋谷の拠点と同じやり方で弱めた（強さ 1 → 0.45、旗の明るさ 0.6 → 0.45）。持ち主の色が見えるのは今までどおり。広場の床の青い輪も薄く細くし、中央の白い光だまりも小さくした
- 交差点らしさを足したもの: 広場の北の縁と大通り側に横断歩道、床の回路の線を2本並びにしてパッドを付けた、床に回路模様のはめ込み4か所、LED ボードを夜に明るく、ボードの下に2本目の流れる表示と制御盤・状態ランプ（ボードの台の内側なので、新しく当たる物はない）

### 目標に届かなかったところ
- draw calls −10% 以上は大通りと塔の広場だけ。路地・裏通路・DATA JUNCTION・アーケードは −3〜−6%
- 三角形は −1〜−2%（影ありで −2〜−3%）で、−10〜15% には届かない
- 原因: 秋葉原で画面に入る三角形 16〜20万のうち、秋葉原の改修分は 1.5万だけ。残りは全マップ共通の建物・街路樹・街灯などの結合メッシュ（マップ全体で1つなので、どこから見ても全部描かれる）、渋谷の改修分（約1.8〜2.2万、秋葉原からも描かれている）、キャラクター（1人約1,550）。秋葉原の分を全部消しても −10% 程度にしかならない
- 届かせるには、全マップ共通の結合メッシュを地区ごとに分けて画面外を省く変更が要る。他の地区の描画に触れるので、今回はやっていない
