## 1. 渋谷の作り
v9.2 の渋谷は、大通りの西が大きな空き地、交差点の南に大きな箱（ヒカリエ相当）が大通りをふさいでいて、範囲内の建物は13棟でした。

**3つのルート**
- **A. MAIN STREET**: 大通り（x −2700）を交差点の南まで通した。広くまっすぐで速いが、上の回廊・両側の店から丸見え
- **B. BACK ALLEY（NEON MAZE）**: 大通りの東の街区を、幅3マス（約114）以上の曲がった路地の迷路にした。どの行・列にもまっすぐ抜ける見通しはない（テストで確認）。入口は空中通路の下のゲート、出口は東・南・北東に3つ。逃走と待ち伏せ用
- **C. UPPER ROUTE**: 交差点を囲む空中回廊「SKY RING」（高さ 140）と、そこから路地の上へ延びる空中通路・北東の回廊。上り下りは3か所の階段（広場の大階段・路地の階段・北東の路地の階段）。見晴らしがよいが、階段の上り下りが遅く、逃げ場が限られる

近道がいつも最善にならないように: 大通りは最短だが隠れられない、迷路は遠回りだが視線が切れる、回廊は上から見えるが降りる場所が3か所しかない。

**ランドマーク（すべて架空のデザイン、実在の広告の再現なし）**
1. **HALO VISION**: 駅前広場の南に立つ円形のスクリーン（直径 300、中心の高さ 190）。マゼンタとミントの光の輪。通常カメラの視界の高さに収まるよう、高く上げずに地面から立てた
2. **SKY RING**: 交差点の上の四角い空中回廊。4面に「SKY RING・渋谷・空中回廊」の帯、脚に紫の光の帯、床下にミントの線
3. **NEON MAZE ゲート**: 空中通路を支える光る門柱と、その下の「NEON MAZE 迷路」看板。路地の入口の目印

**建物（3層で読めるように）**
- 1〜2階: 間口ごとのショーウィンドウ、店名帯、日よけ、柱、店先の光だまり。カメラから 10〜40m で見える部分にいちばん手をかけた
- 中層: 共通のファサード、階ごとのテナント帯、袖看板、大型ビジョン・縦長ビジョン
- 屋上: パラペット、設備、給水タンク、看板・クラウン
- 路地側（サービス面）: 非常階段、配管、室外機。大きな平らな壁を減らした。隣の建物に隠れる面は描かない

**夜**
- 真っ暗にしない。暗さはゲーム上の意味（迷路は暗いまま）を保ちつつ、ネオン・店先の光だまり・回廊の線で形が読めるようにした
- 白飛びの目安（`tools/visual-qa/expo.py`、L≥235 の画素）: 4地点の夜で 1.1〜3.9%（v9.2 は 0.5〜3.8%）。真っ黒につぶれた面もなし
- 光の色はマゼンタ・紫・ミント・ローズ・白だけ。各陣営の色相から 24°以上離れていることをテストで確認

## 2. 上野・東京タワー
- **上野の石段（夜）**: 石段の各段の縁に弱い暖白の線と、左右に低い石灯籠3対を描いた。見た目だけで、夜のルール上の街灯（見え方の判定に使う光）は増やしていない
- **東京タワー下の拠点**: 拠点が階段の降り口にあり、所有勢力の光の柱と足元の光だまりで階段が白飛びしていた。階段の上にある拠点だけ、光の柱と光だまりを弱め（約 0.45 倍）、光だまりの範囲を 0.55 倍にした。ほかの8拠点は変更なし。白飛びの画素 0.6% → 0.1%
