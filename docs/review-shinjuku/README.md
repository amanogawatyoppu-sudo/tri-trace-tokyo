## 1. 新宿の作り
v10.0 の新宿は、明治通りが新宿の中だけ途切れていて（歌舞伎町の2階建てビルと御苑に重なって消えていた）、拠点の西から線路まで灰色の空き地が続き、範囲内の建物は17棟・最高9階でした。

**主戦場: VERTICAL AVENUE**
- 明治通り（x −2700）を歌舞伎町のビルの前から御苑前（戦略拠点）まで1本につなぎ、靖国通りとの交差点 VERTICAL CROSS を新宿の中心にした
- 拠点前広場は大通りに直接面する。拠点から戦略拠点までは大通りが最短だが、両側のデッキ・橋・タワーの足元から丸見え

**高低差: 地上・中層・高所の3段**
- 地上（0）: 大通り、交差点、拠点前広場、路地
- DECK 2（140、渋谷の SKY RING と同じ高さ）: 東のタワーの足元を南北に走るデッキ、交差点の北で大通りを渡る腕、広場の東を下るデッキ。地上への階段は4か所（北端・御苑前・靖国通り・路地の入口）。前の歩道橋はこのデッキに置き換えた
- 高所（280）: T2・T3 の基壇の屋上と、その間で大通りをまたぐ SKY BRIDGE。上り口は DECK 2 からの階段2か所だけ。戦略拠点と広場を見張れるが逃げ場は少ない
- 階段の勾配はすべて歩道橋以下（0.55 以下、テストで確認）

**3つのルート**
- 速いが見られる: 大通り
- 遅いが隠れる: NIGHT LANES（LOCK POINT の北の低層ビルの路地。広場から歌舞伎町のビル・北の通りへ。曲がり角が多い）
- 高い道: DECK 2 → SKY BRIDGE
- 広場 → 路地 → 北端 → デッキ → 広場と一周できるので、行き止まりで追跡が終わらない。待ち伏せ場所は路地の角、デッキの柱の陰、階段の下

**建物（手作り10棟）**
- タワー3本: T1 28階（交差点の北東）、T2 26階、T3 24階（この2本が VERTICAL GATE の両脚）。どれも基壇の上に立つ
- 路地のビル6棟（2〜9階）と T1 の北の5階建て
- 1〜2階は店先とショーウィンドウ、DECK 2 の高さにも店先、中層は各階の床ラインと窓明かり、裏側は配管・室外機・非常階段
- 超高層はオフィスの窓明かりの格子、角を縦に走る白い光のライン、冠部の帯、赤い航空障害灯。T1 の屋上にヘリポート
- 線路側の高架下に店とガード下の照明を付けた

**ランドマーク（すべて架空のデザイン）**
1. **VERTICAL GATE**: T2・T3 と SKY BRIDGE。橋の側面に「VERTICAL GATE・新宿・SKY BRIDGE」の帯。拠点からも戦略拠点からも見える
2. **PILLAR VISION**: T1 の南西の角に巻き付く縦長の LED。下端は DECK 2 の手すりの上（高さ 180）から 560 まで。**案では「約 200 までに主な画面」としていましたが、デッキの手すりと重ならないよう下端を 180 にしたため、通常のカメラでは交差点の南西側から見上げる位置で見えます**（`landmarks.jpg` の中央）
3. **NIGHT LANES ゲート**: 広場から路地に入る口の門。白と深紅のネオン

**夜と色**
- 光の色は白・シアン・紫・深紅だけ。陣営の色（SOL 橙・LUNA 青・STAR 黄）から色相を 24°以上離した（テストで確認）。新宿の一般のビルの看板の色も同じ4色に揃えた（前は赤と水色が陣営色に近かった）
- 路地は暗いまま（隠れるためのルール上の暗さを保つ）。光だまりとネオンで道・階段・デッキの形は読める
- 白飛び（`expo.py`、L≥235 の画素）: 夜 0.0〜0.9%（v10.0 は 0.0〜2.3%）、昼 1.2〜7.1%（v10.0 は 0.1〜9.1%）
